# Project Guidelines

Rules for starting new coding projects. Born from the failure of [[concepts/anomem-postmortem]].

## The Rules

1. **Define the programmer role** using cursor skills before starting
2. **Write SPEC.md first** — no code without specs
3. **Design first, implement second** — don't rush into implementation

## Why

Anomem failed because the foundations weren't set up correctly. The AI coding agent didn't have a clear role defined, specs weren't established upfront, and not enough time was spent on design before diving into implementation.
